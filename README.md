这是一个专为长江雨课堂打造的签到脚本，别的雨课堂简单改改就能用。
可实现自动签到以及伪装签到方式。
登入过一次后，自动生成json文件储存SessionId，下次运行免扫码，只要SessionId没过期就能长期用。

## 启动指引

### 1. 准备环境
请确保安装好必要的依赖包：
```bash
pip install requests qrcode
```

### 2. 运行脚本
```bash
python yuketang_helper.py
```
> 首次运行请用微信扫描二维码登录
