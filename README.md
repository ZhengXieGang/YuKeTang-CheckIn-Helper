这是一个专为长江雨课堂打造的自动化 Python 脚本，别的雨课堂简单改改就能用。
可实现自动签到以及伪装签到方式进行签到。
登入过一次后，自动生成json文件储存SessionId，下次运行免扫码，只要SessionId没过期就能长期用。

## 启动指引

### 1. 准备环境
请确保安装好必要的依赖包：
```bash
pip install requests qrcode
```

### 2. 运行脚本
```bash
python yuketang_helper.py
```
> 首次运行请用微信扫描二维码登录

### 3. 全局功能菜单
扫码完成后，脚本将进入交互菜单：
```text
【雨课堂辅助菜单】
1. 自动扫描课程并用 source=1 签到
2. 自动扫描课程，手动输入 source
3. 手动输入 lesson_id 和 source
4. 退出脚本
```
